# pose-images (built-in OpenPose skeletons)

This fork does not ship the built-in skeleton images (called “FISHER小彩蛋” in the original plugin). Copy `1.png`, `2.png`, … from the `FISHER小彩蛋/` folder of the original [Work-Fisher/ComfyUI-Fisher-Pose](https://github.com/Work-Fisher/ComfyUI-Fisher-Pose) repository (or from their provider) into this `pose-images/` folder. Without them the built-in list in the free-pose editor is empty; everything else works.

The images are listed in `.gitignore` and are not committed.

---

本分支不附带内置骨架图（原插件中的「FISHER小彩蛋」）。请从原仓库 [Work-Fisher/ComfyUI-Fisher-Pose](https://github.com/Work-Fisher/ComfyUI-Fisher-Pose) 的 `FISHER小彩蛋/` 文件夹（或其提供者）把 `1.png`、`2.png`…… 复制到本 `pose-images/` 文件夹。没有这些图片时，自由姿势编辑器的内置列表为空，其他功能不受影响。图片已加入 `.gitignore`，不会被提交。
